# Client

This is a small React application built with Vite.

```bash
npm ci
npm start
```

Use `npm run build` for a production bundle or `npm run preview` to preview
that bundle. The Vite development server proxies `/api` to
`http://localhost:3001`. Set `VITE_API_URL` when the API is hosted elsewhere;
the older `REACT_APP_API_IP` and `REACT_APP_API_PORT` variables remain
supported.
